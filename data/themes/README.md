# 오늘의 주제

같은 앱 안에, 날마다 일상 주제 하나와 그 아래 4~5개 묶음을 보여 줍니다. 기존 명심보감·채근담·증광현문·서양 네 권 순환은 그대로입니다.

## 기둥으로 삼는 원전

성경과 사서삼경(논어·맹자·대학·중용, 시경·서경·주역)을 주제 전반의 기둥으로 삼습니다. 성경 구절은 KJV 영어 원문과 우리 풀이, 사서삼경은 한문 원문과 우리 풀이를 씁니다. 현대 번역서 문구는 베끼지 않습니다.

## 주제를 추가하려면 (코드는 고치지 않습니다)

1. 이 폴더에 JSON 파일 하나를 만듭니다. 이름 예: `32-seonseon.json`
2. 아래 형식을 따릅니다. `id`는 영문 소문자·숫자·하이픈만 (주소 `#theme/그id`에 쓰입니다).
3. `order`는 지금 있는 것보다 **더 큰 숫자**로 뒤에 붙입니다. 가운데에 끼우거나 순서를 바꾸면 지난 날짜의 주제가 밀릴 수 있습니다.
4. 저장소 뿌리에서 `node scripts/build_themes.js` 를 실행합니다. `index.html`과 `data/themes.json`이 자동으로 갱신됩니다. 목차도 파일 목록에서 다시 만들어집니다.

```json
{
  "id": "seonseon",
  "title": "선선함",
  "order": 32,
  "items": [
    {
      "kind": "east",
      "o": "원문",
      "e": "음 (한문이 있을 때)",
      "p": "풀이",
      "source": "출처"
    }
  ]
}
```

나중에 넣는 주제가 이번 바퀴 도중에 끼어들지 않게 하려면 `"since": "2026-12-01"` 처럼 날짜를 적습니다. 그 날짜 이후 **다음 바퀴가 시작될 때부터** 순환에 들어갑니다.


긴 이야기나 대화 속에 짧은 금언이 들어 있는 항목은, 카드의 `o`(원문)·`e`(음)·`p`(풀이)를 그 금언만으로 적고, 지금 쓰던 긴 원문·음·풀이는 `full`·`full_e`·`full_p`에 그대로 둡니다. `full`이 있는 항목만 화면에 「전체 원문 보기」 버튼이 생기고, 같은 카드 안에서 펼치면 긴 원문 속에서 금언이 하이라이트됩니다. `full` 안의 글자는 원전 그대로 두고, `o`는 반드시 `full`에 있는 구절을 그대로 따릅니다(고치지 않습니다). 짧은 금언이 이미 카드 원문인 항목과 채근담 장 단위 항목에는 `full`을 두지 않습니다. 일상 네 권(`D`)과 아침 카톡 문안은 이 필드와 무관합니다.


## 속담 칸

각 주제에는 알맞은 것이 있을 때만, 우리 속담(`proverb_ko`)과 영국 속담(`proverb_en`)을 하나씩 둡니다. 화면과 카톡에서는 다른 항목 뒤에, 우리 속담 → 영국 속담 순으로 같은 자리에 나옵니다. 알맞은 것이 없으면 그 칸은 비웁니다. 억지로 넣지 않습니다.

## 순환 시작일

`_config.json`의 `start`가 주제 순환 0일째입니다. **배포하는 날**로 바꾸면 됩니다. 기존 한마디 시작일(2026-11-05)과는 별개입니다.

## 목차와 주소

- `#YYYY-MM-DD` — 그날의 한마디(네 권). 주제 카드는 이 화면에 두지 않습니다. 위에 있는 「오늘의 주제 · ○○ ▶」를 누르면 그날 주제 화면으로 갑니다. 순환 시작 전에는 이 버튼이 숨겨집니다.
- `#theme-day/YYYY-MM-DD` — 그날의 주제 묶음 전체. 전날/오늘/다음날은 주제 날짜를 옮기고, 「← 한마디」로 같은 날 한마디로 돌아갑니다. 「주제 목차」로 목차에 갑니다.
- `#themes` — 주제 목차 (이 폴더의 파일에서 자동으로 만듭니다)
- `#theme/maljosim` — 날짜와 관계없이 그 주제의 묶음 전체

원문은 일상 글꼴에 있는 한자만 씁니다. 설문해자처럼 확장 영역 글자는 뜻으로 풀어 적어, 네모(□)로 깨지지 않게 합니다.

## 저작권

지어내지 않습니다. 풀이는 우리 글(또는 앱에 이미 있는 풀이)입니다. 명언은 죽은 지 70년이 넘고 출처가 확인된 것만, 짧은 현대 법칙·격언(머피의 법칙 등)은 한 줄 표어와 누구·언제 정도의 출처만 씁니다. 현대 책의 긴 본문·노래 가사는 넣지 않습니다.

## 이 폴더에 아직 안 넣은 것

- `任`(符也。从人壬聲)·`僞`(詐也。从人爲聲)는 『설문해자』 권8에서 확인했으나, 「한자로 보는 사람살이」에는 仲·仁·信·休·保를 먼저 실었습니다. 같은 형식으로 파일에 항목만 더하면 됩니다.
- 경청, 마음 다스림은 확인된 묶음이 충분하지 않아 아직 파일을 만들지 않았습니다. 구절이 모이면 위 방법 그대로 추가하면 됩니다.
